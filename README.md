# nissajean.com

Static website for Nissa Jean, Backend Systems Specialist.

## Files
- `index.html`: the whole site (Home, Services, Work, About, Book a Call), in plain HTML, CSS and a little JavaScript
- `assets/`: photo and project screenshots
- `CNAME`: custom domain for GitHub Pages

## Publish with GitHub Pages
1. Push these files to the root of a repository.
2. In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
3. The custom domain `nissajean.com` is set by the `CNAME` file.
4. After DNS is connected, turn on **Enforce HTTPS**.

## Editing
- Text: edit `index.html` directly.
- Colors: the CSS variables at the top of the `<style>` block.
- Booking link: search for `calendar.app.google`.
